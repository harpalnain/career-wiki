## One-line summary
Maya Sharma's 2023 resume — Senior Backend Engineer, 7 years across Flowcart, DataNimbus, and TCS.

## Key claims
- 7 years building distributed systems and data pipelines; strong in Python, Go, cloud-native architecture.
- **Flowcart** (Senior Backend Engineer, Mar 2021 – Present): led Django monolith → Go microservices migration, cut p99 API latency 800ms → 120ms; designed Kafka + Go event-driven order pipeline at ~500k orders/day with exactly-once semantics; mentored 4 junior engineers, introduced code review standards reducing production incidents ~30%.
- **DataNimbus** (Backend Engineer, Jul 2018 – Feb 2021): built Python/Airflow ETL framework ingesting 12 sources into Redshift; cut nightly batch runtime 6h → 90min via partitioning + parallelism; owned on-call rotation, authored runbooks still in use.
- **TCS** (Software Engineer, Jun 2016 – Jun 2018): Java/Spring backend for a banking client; maintained legacy SOAP services, migrated two to REST.
- Skills: Python, Go, Java, PostgreSQL, Kafka, Airflow, AWS (EC2, S3, Lambda, Redshift), Docker, Kubernetes, Terraform.
- Education: B.Tech, Computer Science — VIT Vellore, 2016.
- Notable: Speaker, PyCon India 2022 ("Exactly-once is a lie (and what to do about it)"); maintainer of a small Airflow operator library (~300 stars).
